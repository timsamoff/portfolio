# Tim Samoff | Portfolio
A simple one-page web-based portfolio that uses a slick JSON-based admin system.

## Test it!
* [Live Portfolio](https://samoff.com/portfolio)
* [Admin (will not save changes)](https://samoff.com/portfolio/admin.html)
	* Admin allows the addition of new portfolio pieces, editing current pieces, and organization of pieces. All changes are saved into a single JSON file that is automatically imported into the main portfolio HTML.
