How This Works

Real Site

The live portfolio uses a local server to save your projects to a JSON file. This file is then published with the static site. Perfect for portfolios that don't need a database.

Admin Panel → Local Server → projects.json → Live Site

This Demo

This demo simulates the exact same workflow, but saves everything to your browser's localStorage instead of a server. No setup required. Just open and start editing.

Admin Panel → localStorage → Live Demo

Try it out: Add a project, publish it, then click "View Live Site" to see your changes instantly. Everything is saved automatically. Refresh the page and your work persists.
