Portfolio Demo

This is a fully functional demo of the portfolio management system. All project data is stored locally in your browser using localStorage, so you can add, edit, and rearrange projects without a server or database.
(Learn more about it at the Admin Panel.)

The demo includes a collection of sample projects with placeholder images and categories to showcase the portfolio grid, filtering, and media carousels. Use the Admin Panel to create new projects, publish or unpublish them, reorder the list via drag-and-drop, and see changes reflected immediately on the live site. Everything you do is saved automatically to your browser — refresh the page and your work persists. To start fresh, click the Reset Demo Data button in the Admin panel.
